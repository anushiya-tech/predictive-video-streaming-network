# Predictive Video Streaming Network

## Project Overview

The Predictive Video Streaming Network is a machine learning-based video streaming system designed to predict network conditions and reduce buffering. It helps select suitable video quality based on network performance for smoother playback.

## Features

- Predictive Network Monitoring
- Buffer Risk Prediction
- Adaptive Bitrate Control
- Interactive Dashboard
- FastAPI Backend
- Performance Evaluation

## Technologies Used

- Python
- Machine Learning
- FastAPI
- HTML, CSS, JavaScript
- Scikit-learn
- Pytest

## Project Structure

- `app/` – Application frontend and backend
- `configs/` – Configuration files
- `docs/` – Project documentation
- `reports/` – Evaluation reports and results
- `scripts/` – Data processing, training, and evaluation scripts
- `src/` – Core machine learning and prediction modules
- `tests/` – Automated tests
- `requirements.txt` – Python dependencies
- `run.py` – Application entry point

## Installation

Clone the repository:

```bash
git clone https://github.com/anushiya-tech/predictive-video-streaming-network.git
cd predictive-video-streaming-network
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
python run.py
```

Open `http://127.0.0.1:8000` in your browser if the application starts on that address.

## Run Tests

```bash
pytest -v
```

## Project Goal

The goal is to improve video streaming reliability by predicting network changes and selecting suitable video quality to reduce buffering.
